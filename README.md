# ChemiLab · 化学实验室

一个面向高中化学的 **宏观 / 微观双视角** 化学实验模拟器。点选试剂加入烧杯，观察颜色、沉淀、气泡和温度变化；一键切换到微观粒子视图，观察离子汇聚、生成沉淀、气体逸出。

> 微观粒子是教学示意，不是真实的分子动力学模拟。粒子数量按物质的量缩放，颜色与种类与宏观体系保持同步。

## 快速开始

```bash
npm install
npm run dev      # 打开 http://127.0.0.1:5173
npm test         # 运行化学数据与模拟引擎测试
npm run build    # 类型检查 + 生产构建
```

## 功能

- **宏观视图**：烧杯、液面、颜色渐变、浑浊、沉淀沉降、气泡、温度计、倾倒/滴加/药匙动画。
- **微观视图**：离子/分子布朗运动、反应汇聚与闪光、沉淀聚集下沉、气体上浮、粒子图例、缩放入场。
- **精选反应**：约 28 个高中经典反应，覆盖沉淀、酸碱中和、气体生成、金属置换、催化分解、络合变色、沉淀溶解。
- **试剂架**：29 种常见试剂，按溶液/酸/碱/固体/指示剂/其他分组。
- **信息面板**：分子方程式、离子方程式、实验现象、反应进度、体系成分、pH、温度和观察记录。
- **气体检验**：产生气体后，在“体系”面板点击“检验气体”，选择带火星木条、澄清石灰水或点燃，根据实际气体给出复燃、变浑浊、淡蓝色火焰/爆鸣等结果。
- **预设实验**：蓝色沉淀、黄金雨、铁钉置换、酸碱指示、氧气生成、血红色检验。
- **控制**：宏观/微观切换、0.5×/1×/2× 速度、暂停/继续、重置、音效开关。
- **音效与特效**：Web Audio 实时合成倾倒、固体落杯、滴加、反应嘶嘶声/气泡、放热/吸热氛围、完成提示音；宏观视图带反应闪光、扩散光环、火花、烧杯辉光、热浪/冷光、液面涟漪和颜色混合过渡。

## 音效与特效

音效全部由 Web Audio API 实时合成，不依赖外部音频文件：

- 首次点击试剂或预设时解锁音频上下文；顶栏扬声器按钮可随时静音。
- 倾倒、固体落杯、滴加使用不同音色；反应开始时按沉淀、气体、放热、吸热、络合等类型生成不同声音；气体持续产生气泡声，反应完成有提示音。
- 宏观视图：反应开始闪光、扩散光环、粒子火花、烧杯边缘辉光、热浪/冷光、液面涟漪、溶液颜色混合过渡、温度计光晕。
- 微观视图：反应窗口边缘按反应类型变色并脉冲，反应开始时叠加柔光。

## 气体检验

反应生成气体后，右侧“体系”面板会出现“检验气体”按钮。当前支持三种高中常见检验方法：

- **带火星木条** → O₂：木条复燃
- **澄清石灰水** → CO₂：石灰水变浑浊
- **点燃** → H₂：淡蓝色火焰 + 爆鸣声（实验前应先验纯）

选错方法时不会直接揭示答案，而是提示“现象不符”，可以换一种方法再试。气体检验的判定逻辑在 `src/domain/gasTests.ts`，并配有单元测试。

## 技术栈

- Vite + React 18 + TypeScript

- Web Audio API（实时合成音效）
- Zustand（UI 状态）

## 架构

```
React UI（试剂架、舞台、信息面板）
        │ 10 Hz 订阅快照
        ▼
LabEngine（唯一事实源）
  ├─ 物种 / 试剂 / 反应数据
  ├─ 反应匹配、优先级、限量试剂
  ├─ 宏观状态：体积、颜色、浊度、沉淀、气体、温度、pH
  └─ 微观映射：物质的量 → 粒子数量
        │ 逐帧读取
        ▼
Canvas 渲染层
  ├─ MacroRenderer：烧杯、液体、沉淀、气泡、倾倒
  └─ MicroRenderer：粒子、布朗运动、反应汇聚、沉降、气体
```

关键设计：

- **以净离子反应为核心**：试剂加入后拆成离子，反应规则写成 `Cu²⁺ + 2OH⁻ → Cu(OH)₂↓`，旁观离子自然留在体系中。
- **一次只跑一个反应**：按 `priority` 选择当前反应，消耗到限量试剂为止，再重新匹配。结果确定、动画清晰。
- **单一事实源**：宏观颜色、沉淀量、微观粒子数都从同一份引擎状态派生。
- **固定步长 + 可变帧率**：引擎在渲染循环中以最多 50 ms 的步长推进，速度倍率只影响模拟时间。
- **颜色在 OKLab 空间混合**：避免蓝 + 黄变成脏灰；沉淀作为浊度/沉降层单独处理。

## 化学模型与边界

### 反应数据

每个反应包含：

- `reactants` / `products`：净离子方程式中的物种与系数
- `catalyst`：可选催化剂（如 MnO₂）
- `priority`：竞争反应优先级
- `durationMs`：1× 速度下的完整反应时长
- `deltaH`：反应热，用于温度变化
- `display.molecular` / `display.ionic`：分子方程式与离子方程式
- `phenomenon`：中文实验现象
- `effects`：气体、沉淀、放热等视觉提示

### pH

采用高中层面的简化模型：

- 强酸/强碱按自由 H⁺ / OH⁻ 计算
- 醋酸、氨水、碳酸根、碳酸氢根按一元弱平衡近似
- 不处理活度系数、多元平衡和精确缓冲体系
- pH 低于约 7 的极稀弱碱/弱酸会被水自偶电离拉回中性附近

### 颜色与浊度

- 溶液颜色 = 各有色物种按 `物质的量 × tintStrength` 在 OKLab 空间加权混合
- 沉淀先以悬浮颗粒贡献浊度，再逐渐转入沉降层
- 指示剂颜色由 pH 区间插值：酚酞 8.2–10.0、甲基橙 3.1–4.4、石蕊 5–8

### 不在本期范围内

- 真实的分子动力学/量子化学计算
- 通用反应推导引擎（氧化还原、络合、平衡的完整求解）
- 加热、通气、试管、酒精灯等实验操作
- 3D 场景、有机化学、晶体结构
- 账号、云存储、实验保存/分享

## 如何新增一个反应

1. 在 `src/domain/species.ts` 中确认反应物/产物物种存在；没有就新增：

```ts
solid('mgoh2', 'Mg(OH)2', '氢氧化镁', '#F2F0E8', true)
```

2. 在 `src/domain/reactions.ts` 中新增反应，反应物/产物写净离子形式：

```ts
{
  id: 'mg-oh',
  reactants: [
    { speciesId: 'mg2', coeff: 1 },
    { speciesId: 'oh', coeff: 2 },
  ],
  products: [{ speciesId: 'mgoh2', coeff: 1 }],
  priority: 70,
  durationMs: 2200,
  deltaH: -15,
  display: {
    molecular: molecular(
      [part('MgCl2'), part('NaOH', 2)],
      [part('Mg(OH)2', 1, 's'), part('NaCl', 2)],
    ),
    ionic: ionic([['mg2', 1], ['oh', 2]], [['mgoh2', 1]]),
  },
  phenomenon: '产生白色沉淀。',
  effects: { precipitate: '#F2F0E8' },
}
```

3. 如果它是某个试剂的组成成分，在 `src/domain/reagents.ts` 中补充试剂。
4. 运行 `npm test`。配平测试会检查元素守恒与电荷守恒；任何不匹配都会失败。
5. 如需预设演示，在 `src/domain/presets.ts` 中追加步骤。

## 视觉与交互说明

- 桌面优先，窄屏会自动堆叠布局。
- 烧杯容量 80 mL；每次液体试剂加入 10 mL。
- 试剂卡片点击加入；预设实验会按顺序自动加入试剂。
- 反应过程中切换宏观/微观不会重置状态。
- 微观视图中的粒子标签、图例和物质的量对应同一份引擎状态。
